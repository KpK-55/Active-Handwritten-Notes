RECALL STUDIO — BUILD 01

Upload index.html, manifest.webmanifest and sw.js to the ROOT of your GitHub repository, then let GitHub Pages deploy.
Open the HTTPS GitHub Pages URL on your tablet and PC. Do not open index.html directly from a file manager.

Included in this first build:
- StarNote-inspired dark library and workspace layout
- Subject list, note creation, search and note thumbnails
- Compact top toolbar and right-side page/recall panel
- Stylus-only drawing (finger does not draw)
- Pen, pencil, highlighter, basic whole-stroke eraser
- Colour and thickness controls
- Blank, ruled and grid paper
- Fixed page and infinite-workspace mode
- Multiple pages, undo/redo, zoom controls
- Local IndexedDB storage and JSON backup import/export
- Basic PWA manifest and service worker

Not included yet: real lasso selection, moving selected strokes, partial eraser, image/PDF placement, Cloze rendering, image/area occlusion, chapter review, Google Drive sync, install icons, pressure-sensitive width. The recall buttons are placeholders, not functional recall tools yet.

IMPORTANT: This is an early foundation build. Test on sample notes first. Browser data is local to each device and does NOT sync between devices. Export backups regularly while testing.
